# Contributing to PowerFM

PowerFM curates original and community-contributed open-source projects for power and energy foundation models. Contributions should make the collection more useful, reproducible, and trustworthy—not just add another link.

## Proposing a project

Before opening a pull request, verify the project’s official source and provide the information below in the README entry or the relevant catalog location:

- **Project and maintainers:** official project name and canonical repository or project page.
- **Capability:** the power/energy task addressed (for example, load forecasting, power flow, contingency analysis, or time-series generation).
- **Data and model access:** direct links to the dataset, model weights, benchmark, or code when publicly available. Label unavailable or access-restricted artifacts explicitly.
- **License:** the license for the code, dataset, and model weights separately when they differ. Do not infer a model or dataset license from the repository license.
- **Evidence and scope:** cite the project’s own documentation or paper for claims about tasks, scale, topology coverage, or performance. Distinguish reported results from independently reproduced results.
- **Reproducibility:** link to installation and evaluation instructions, and note material requirements or limitations that a user would need to reproduce the work.

## Pull request checklist

- [ ] The project is relevant to power systems or the energy domain.
- [ ] Links point to canonical, maintained sources and have been checked manually.
- [ ] Dataset, code, and model licensing are stated accurately; unknown licensing is marked as unknown.
- [ ] Claims are supported by the linked project documentation or publication.
- [ ] Existing entries and local assets are not removed or changed unnecessarily.
- [ ] The README renders correctly and any added local image paths resolve.

PowerFM is a curated index as well as a home for original work. Please keep entries factual and concise, and avoid implying that listing a project constitutes an endorsement or independent validation.
